# GltfInstancingAndTilingTool 参数说明

本文档列出项目中所有可配置参数及其含义、类型、默认值与适用场景。

---

## 一、基础配置

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `input_directory` | string | - | 输入目录路径，包含待处理的 GLB 文件 |
| `output_directory` | string | - | 输出目录路径 |
| `merge_all_glb` | bool | false | 是否将所有 GLB 合并为一个模型后再做实例化检测 |
| `instance_limit` | int | 2 | 最小实例数阈值：实例数 ≥ 此值的组才归类为实例化组 |
| `allow_non_uniform_scale_instancing` | bool | false | 是否允许非均匀缩放（xyz 不同）的 mesh 被归为同一实例组 |
| `mesh_segmentation` | bool | false | 是否启用网格分割，为 Quadtree 生成按空间分割的 GLB |
| `csv_directory` | string | - | CSV 目录，用于构件 ID 与 mesh 的映射（可选） |

---

## 二、实例化检测（Stage 1 / semantic_material_geometric 模式）

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `instancing_detection_mode` | string | semantic_material_geometric | 实例化检测模式，当前仅支持 semantic_material_geometric |
| `semantic_hash_fields` | string | "category,family,type" | 语义分组字段，逗号分隔，如 category,family,type。空表示不做语义约束；仅 category 则只按类别分组 |
| `similarity_thresholds` | string | "0.95,0.90,0.85,0.80,0.75" | 各 LOD 相似度阈值，逗号分隔，值域 [0,1]，越高越严格 |
| `hlod_similarity_threshold` | double | 0.70 | HLOD/非实例化 LOD 后处理实例化检测的相似度阈值 |
| `hausdorff_max_sample_points` | size_t | 2000 | Hausdorff 点云采样上限，0 表示不采样；越小越快但可能更不精确 |
| `allow_unknown_cross_mesh_clustering` | bool | false | 语义为 Unknown 的 mesh 是否允许跨 mesh 聚类 |
| `material_filter_mode` | string | "none" | 材质过滤模式：`none`（不过滤）、`hash`（材质+纹理 hash 相同才比较）、`index`（材质索引相同才比较） |
| `semantic_data_path` | string | - | 语义数据路径：单文件或文件夹；若为文件夹，按 input_directory 下 GLB 文件名匹配同名 .RISCRVT |
| `semantic_input_directory` | string | - | 可选；当 semantic_data_path 为文件夹时，用于匹配的 GLB 来源目录（默认用 input_directory）。HLOD 使用 split/segmented 输入时，自动设为原始 input_directory |

**语义映射保留**：Non-instanced LOD 与 HLOD 的 GLB 来源与原始输入不同，工具会在 mesh 名中保留 `glbStem|meshHashId` 格式，以便后处理实例化检测时正确查找语义（RISCRVT）。

---

## 三、Instance LOD（实例化 LOD）

对 Stage 1 检测到的实例化 mesh 做语义+几何聚类，生成多级 LOD。LOD 越粗糙，相似度阈值越宽松。

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_instance_lod_generation` | bool | false | 是否启用实例化 LOD 生成 |
| `lod_level_count` | int | 5 | LOD 层级数（如 5 表示 LOD5→LOD1） |
| `target_screen_sse` | double | 16.0 | 屏幕空间误差，用于 tileset 的 geometricError |
| `instance_lod_similarity_thresholds` | string | "0.95,0.90,0.85,0.80,0.75" | 每级 LOD 的 Hausdorff 相似度阈值，LOD5→LOD1 逐步放宽 |
| `instance_lod_instance_limit` | int | -1 | 实例数阈值；-1 表示使用 Stage 1 的 instance_limit |
| `instance_lod_material_filter_mode` | string | "none" | 材质过滤：none / hash / index |
| `lod4_size_tolerance` | double | 0.05 | LOD4 体积聚类回退（similarityThresholdsPerLevel 为空时） |
| `lod3_aspect_ratio_tolerance` | double | 0.20 | LOD3 长宽比聚类回退 |
| `enable_semantic_check` | bool | true | 是否启用语义检查（Family/Category 聚类） |
| `enable_geometric_check` | bool | true | 是否启用几何检查（体积、长宽比等） |

---

## 四、Non-instanced LOD（非实例化 LOD）

对 Stage 1 的非实例化 mesh 做网格简化 LOD，可选在简化后再做实例化检测。LOD 越粗糙，相似度阈值越宽松。

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_non_instanced_lod_generation` | bool | false | 是否对非实例化 mesh 做网格简化 LOD |
| `non_instanced_lod_level_count` | int | 3 | 非实例化 LOD 层级数 |
| `non_instanced_lod_ratio` | double | 0.5 | 每级简化的目标比例（如 0.5 表示保留约 50% 三角形） |
| `non_instanced_min_simplify_index_count` | size_t | 300 | 最小索引数，低于此值不再简化 |
| `enable_non_instanced_lod_instancing` | bool | false | 非实例化 LOD 生成后，是否对每个 LOD 级再做实例化检测 |
| `enable_non_instanced_lod_clustering` | bool | false | 实例化检测后是否再做 Family/Category 层级聚类（同 Instance LOD 的 LOD4/LOD3） |
| `non_instanced_lod_similarity_thresholds` | string | "0.95,0.90,0.85" | 每级 LOD 的相似度阈值，越粗糙越宽松 |

## 五、Quadtree / HLOD 配置

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_quadtree` | bool | false | 是否启用 Quadtree HLOD 流程 |
| `quadtree_max_depth` | int | 6 | Quadtree 最大深度 |
| `quadtree_max_objects_per_tile` | int | 50 | 每个 tile 最大对象数 |

---

## 六、HLOD 实例化检测参数

用于 Quadtree 父 tile、Non-instanced LOD 后处理等场景的实例化检测，可与 Stage 1 参数不同。未显式设置时沿用 Stage 1 对应参数。父 tile 层级越粗，相似度阈值越宽松。

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_hlod_clustering` | bool | false | 实例化检测后是否再做 Family/Category 层级聚类（同 Instance LOD 的 LOD4/LOD3） |
| `hlod_similarity_threshold` | double | 0.70 | 单阈值模式（hlod_similarity_thresholds 为空时使用） |
| `hlod_similarity_thresholds` | string | "0.70,0.65,0.60,0.55,0.50" | 每层级相似度阈值，父 tile 越粗越宽松 |
| `hlod_instance_limit` | int | -1 | HLOD 实例数阈值；-1 表示使用 Stage 1 的 instance_limit |
| `hlod_allow_non_uniform_scale_instancing` | bool | false | HLOD 是否允许非均匀缩放实例化 |

**说明**：Quadtree 父 tile、Non-instanced LOD 后处理的实例化检测沿用二节的 `semantic_hash_fields`、`material_filter_mode`、`allow_unknown_cross_mesh_clustering`、`hausdorff_max_sample_points`；HLOD 特有：`hlod_similarity_thresholds`、`hlod_instance_limit`；Non-instanced LOD 特有：`non_instanced_lod_similarity_thresholds`。

| `experiment3_name` | string | "experiment3_mixed_hlod" | 实验 3 文件夹名 |
| `run_cross_glb_hlod_experiment` | bool | false | 是否运行实验 6（跨 GLB HLOD 对比） |
| `experiment_dataset_name` | string | "" | 数据集名称，用于组织输出文件夹 |
| `experiment_strategy_id` | string | "" | 策略 ID，用于实验 1 等对比实验 |

## 九、配置文件格式

- 格式：`key = value`，每行一对
- 注释：以 `#` 开头
- 布尔值：`true` / `false` / `1` / `0` / `yes` / `no`（不区分大小写）
- 示例见 `experiment_config_template.txt`

## 十、Analysis CSV 输出说明

各阶段会在 `analysis` 目录下生成 CSV，用于统计实例化比例与实例化增加度：

| 文件路径 | 说明 |
|----------|------|
| `01_instancing/analysis/instancing.csv` | Stage 1 实例化检测统计 |
| `02_instance_lod/analysis/instance_lod.csv` | Instance LOD 每级：Unique Meshes, Total Instances, **Instancing Ratio**, **Instancing Increase**（基线=LOD5） |
| `02_non_instance_lod/analysis/non_instance_lod_instancing_analysis.csv` | Non-instanced LOD 实例化后处理每级：UniqueMeshes, TotalInstances, NonInstancedCount, **Instancing Ratio**, **Instancing Increase**, **Instancing Increase Ratio (%)**（需 enable_non_instanced_lod_instancing） |
| `03_hlod/hlod_analysis.csv` | HLOD 每 tile：InstancingRatio, **Instancing Increase**, **Instancing Increase Ratio (%)**；文末 Per-Level Summary：每级聚合的 Instancing Ratio、Instancing Increase、Instancing Increase Ratio (%)（基线=leaf level） |

**Instancing Ratio** = Total Instances / Unique Meshes（每 unique mesh 平均实例数）  
**Instancing Increase** = 当前级 Instancing Ratio − 基线级 Instancing Ratio  
**Instancing Increase Ratio (%)** = (Instancing Increase / 基线 Instancing Ratio) × 100（相对增加比例）
